# Sole Serenity

Working demo of the Sole Serenity Reflexology & Reiki website (Calgary). Nothing is real or charged.

- `/` the website. Booking, gift cards and packages work, with a pretend Stripe checkout.
- `/admin/` Melanie's admin page and the emails sent. It shows what was booked or bought on the website **in the same browser** (the demo data is saved in that browser only).
- `/demo/` the all-in-one demo (website, admin and emails in tabs).
